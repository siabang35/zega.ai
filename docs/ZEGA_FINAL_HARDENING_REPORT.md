## 2. Security Invariants

- **Single Settlement Route**: Exactly ONE POST `/v1/zeroclaw/settlement/record` endpoint exists.
- **Server-Controlled Demo Mode**: Request body `isDemo` parameter is strictly ignored; settlement security is governed strictly by `process.env.ZEGA_DEMO_MODE === 'true'`.
- **Timing-Safe Webhooks**: All HMAC signature verifications use `crypto.timingSafeEqual`.
